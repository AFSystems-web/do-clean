# do clean — спецификация

Нативный чистильщик для macOS. Красивый, честный и безопасный: показывает, **что** удаляется,
**почему** это безопасно и **сколько** места вернётся. Работает для любого мака, но знает про
тяжёлый мусор творческих и dev-машин: Adobe, Xcode, Blender, AI-модели.

Типичный «творческий» мак (ориентир, ради которого всё делается):

| Что | Размер |
|---|---|
| After Effects disk cache (`~/Library/Caches/Adobe/After Effects`) | 46 ГБ |
| Xcode iOS DeviceSupport (4 старых iOS) | 24 ГБ |
| Загрузки | 14 ГБ |
| Movies | 11 ГБ |
| HuggingFace-модели (`~/.cache/huggingface`) | 10 ГБ |
| Симуляторы | 4,6 ГБ |
| `/private/var/folders` + `/tmp` | ~4 ГБ |

---

## 1. Главный принцип: три уровня безопасности

Весь мусор делится на уровни. Пользователь всегда видит уровень и может вычистить **всё**,
но к опасному добирается осознанно.

| Уровень | Цвет | Что это | По умолчанию | Как удаляется |
|---|---|---|---|---|
| **Безопасно** | зелёный | Кэши, логи, временные файлы, DerivedData. Всё это программы создают заново | ✅ отмечено | Удаляется сразу, место освобождается мгновенно |
| **Проверь** | жёлтый | Можно удалить, но придётся скачать или пересобрать: DeviceSupport, симуляторы, AI-модели, кэши пакетных менеджеров, Корзина | ☐ не отмечено | В Корзину (кроме самой «Корзины») |
| **Личное** | красный | Твои файлы: Загрузки, большие и старые файлы, дубликаты, установщики `.dmg/.pkg`, Movies | ☐ только выбор по файлам | В Корзину, всегда с превью списка файлов |

Режимы сканирования на главном экране:
- **Быстро:** только зелёный уровень, одна кнопка «Очистить».
- **Глубоко:** зелёный и жёлтый.
- **Всё:** все три уровня. Красный всегда раскрывается до списка файлов, а не одной галочкой.

## 2. Структура категорий

Каждая категория — это **правило** (Rule) в декларативном каталоге `Rules/*.json`,
а не код. Новую категорию можно добавить без правки Swift.

### Система (зелёный)
- Пользовательские кэши `~/Library/Caches/*` (кроме исключений)
- Логи `~/Library/Logs`, `DiagnosticReports`
- Временные файлы (`$TMPDIR` старше 3 дней)
- Кэши браузеров: Safari, Chrome, Arc, Firefox, Yandex (только кэш, **не** профиль/пароли/историю)
- Кэш Mail-вложений (`Mail Downloads`)
- Кэши QuickLook и иконок

### Творческие программы (зелёный, только когда программа закрыта)
- After Effects: disk cache
- Premiere Pro, Media Encoder: Media Cache, Media Cache Files, peak-файлы
- Adobe Creative Cloud: служебные кэши
- Blender: `~/.cache/cycles`, временные рендеры `/tmp/*.png|exr` старше 1 дня
- DaVinci Resolve: CacheClip (если найден)
- Final Cut / Motion: render files (жёлтый, обнаружение по библиотекам)
- Кэши своих панелей и плагинов: через личные правила `~/Library/Application Support/do clean/Rules/*.json` (не в репозитории)

### Разработка
- Xcode DerivedData (зелёный)
- Xcode Previews, кэши модулей (зелёный)
- iOS DeviceSupport: все версии, кроме самой новой (жёлтый)
- Симуляторы: недоступные (`xcrun simctl delete unavailable`, зелёный) и все данные симуляторов (жёлтый)
- Xcode Archives (жёлтый)
- Homebrew cache, `brew cleanup` (зелёный)
- npm/yarn/pnpm, pip, uv caches (жёлтый)
- `node_modules` в проектах, не открывавшихся больше 30 дней (жёлтый, по файлам)
- Docker (жёлтый, если установлен: показать `docker system df`, предложить prune)

### AI и модели (жёлтый)
- HuggingFace hub cache, по моделям с размером и датой последнего использования
- Ollama, LM Studio модели
- Рантаймы Codex/Claude (`~/.cache/codex-runtimes`, старые версии)

### Личные файлы (красный)
- **Загрузки:** фильтры «старше 30/90 дней», «установщики .dmg/.pkg/.zip», «всё»
- **Большие файлы:** файлы >500 МБ во всём домашнем каталоге, сортировка по размеру
- **Дубликаты:** одинаковые файлы (размер → быстрый хеш → полный SHA-256)
- **Старые файлы:** не открывались больше года
- **Корзина** (жёлтый): очистка самой Корзины, это единственное безвозвратное действие в жёлтом

### Никогда не трогаем (жёстко зашито, не настраивается)
- `~/Documents`, `~/Desktop`, `~/Pictures`, Фото-библиотеки, iCloud Drive: их нет в сканировании,
  кроме поиска «Большие файлы» и «Дубликаты», где только превью и Корзина
- Keychains, профили браузеров, `~/Library/Mobile Documents`, `~/Library/Application Support`
  (кроме явно перечисленных кэшей)
- Системные папки `/System`, `/usr`, `/Library` (без прав root мы туда не лезем вообще)
- Файлы открытых прямо сейчас программ: правило с `requiresAppClosed` пропускается,
  если процесс запущен, и UI предлагает «Закрой After Effects, чтобы освободить 46 ГБ»

## 3. Экраны

1. **Главная (Dashboard).** Сетка «стеклянных» карточек как на референсе: большое точечное
   число свободного места, кольцо диска, карточки категорий с цветным размытием и точечными цифрами
   (ГБ). Внизу кнопки режима (Быстро / Глубоко / Всё) и большая кнопка **Сканировать**.
2. **Сканирование.** Живая анимация: карточки «наполняются» по мере обхода, бегущая шкала-рисочки,
   счётчик найденного.
3. **Результаты.** Список категорий по уровням, у каждой: галочка, размер, «почему безопасно»,
   кнопка «Показать файлы» (раскрытие до файлов, Reveal in Finder, QuickLook).
4. **Очистка.** Прогресс, затем экран «Освобождено 82,4 ГБ» с анимацией и сравнением «было → стало».
5. **Инструменты.** Большие файлы, Дубликаты, Загрузки, `node_modules`: отдельные интерактивные списки.
6. **История.** Сколько освобождено всего, по датам, график.
7. **Настройки.** Исключения (папки и правила), напоминание раз в N дней, порог «больших файлов»,
   удалять или в Корзину для зелёного уровня, язык RU/EN, автозапуск в меню-баре.
8. **Меню-бар.** Мини-виджет: свободное место точечными цифрами, «Быстрая чистка» в один клик.
9. **Онбординг.** 3 экрана: что делает, как устроены уровни, выдача Full Disk Access
   (кнопка открывает нужную панель Настроек, приложение само замечает выдачу доступа).

## 4. Визуальный язык (по референсу «AI OS»)

- Тёмный фон `#0B0B0D`, карточки со скруглением 28 pt, полупрозрачное стекло и **цветное
  меш-размытие** внутри (у каждой категории своя пара цветов: Adobe — красный/малиновый,
  Xcode — синий/циан, AI — фиолетовый, Загрузки — лайм/оливковый, Система — зелёный/бирюза).
- **Точечный шрифт** (dot-matrix) для всех чисел: собственный рендер на SwiftUI Canvas
  (сетка 5×7 точек на цифру), без внешних шрифтов и лицензий.
- Шкалы-«рисочки» с маркером-треугольником, как в карточках «Today's Metrix» и «Color».
- Заголовки: SF Pro Display Semibold, подзаголовок полупрозрачный второй строкой («Кэши / After Effects»).
- Анимации: spring, плавный пересчёт цифр, мягкое «дыхание» градиентов. Есть Reduce Motion.
- Светлой темы нет: тёмная тема и есть фирменный стиль.

## 5. Техника

- **Swift 6, SwiftUI, macOS 14+** (у друзей могут быть не самые новые маки).
- Сборка через **Swift Package Manager** + `Tools/bundle.sh`, который собирает `.app`
  (Info.plist, иконка, ad-hoc подпись) и `.dmg`. Xcode-проект не нужен, CLI-сборка воспроизводима.
- Без App Sandbox (иначе нельзя читать чужие кэши). Нужен **Full Disk Access**, проверка
  через чтение `~/Library/Safari`.
- Модули:
  - `DoCleanCore`: Rule, Scanner (параллельный обход через `FileManager` + `URLResourceValues`,
    `totalFileAllocatedSize`), Cleaner (delete / trashItem), SafetyGuard (запрещённые пути),
    AppStateProbe (запущенные процессы), DuplicateFinder, History (JSON в Application Support).
  - `DoCleanUI`: экраны, DesignSystem (GlassCard, MeshBlur, DotMatrixNumber, TickScale).
  - `doclean-cli`: `doclean scan --json`, `doclean clean --dry-run`. Нужен для тестов и для меня.
- **SafetyGuard — последняя линия обороны:** любой путь перед удалением проходит
  проверку: внутри разрешённого корня правила, не симлинк наружу, не в списке «никогда»,
  не изменён после сканирования. Это покрыто тестами.
- **Тесты:** XCTest на фейковой файловой системе во временной папке: каждое правило, SafetyGuard,
  дубликаты, dry-run. Плюс `-selftest` режим в самом приложении. Цель: 0 падений.

## 6. Раздача друзьям (GitHub)

- **Приватный** репозиторий `do-clean` друзья добавляются
  коллабораторами (иначе они не увидят ни код, ни релизы).
- GitHub Release с `doclean-<версия>.dmg`, собирается `Tools/release.sh`.
- Подписи Apple Developer ID нет, поэтому macOS при первом запуске скажет «не удалось проверить».
  В README будет инструкция на 2 шага: правый клик → Открыть, или
  `xattr -dr com.apple.quarantine "/Applications/do clean.app"`. Если появится Developer ID,
  добавим нотаризацию, и предупреждение уйдёт.
- В репо: README (RU + EN, скриншоты), CHANGELOG, `.gitignore`, лицензия (решить: MIT или «все права»).
- Проверка обновлений внутри приложения через GitHub Releases API (для приватного репо нужен
  токен, поэтому в v1 только ссылка «Проверить на GitHub»).
