# do clean — план ночной разработки

Цель: к утру готов **v1.0.0**: собранный `.dmg`, все экраны из SPEC, тесты зелёные,
приватный репозиторий на GitHub с релизом. Правки вносятся потом, отдельными итерациями.

Правила ночи:
- Этапы идут **по порядку**, каждый заканчивается коммитом `stage N: …` и зелёными тестами.
- Ни одного реального удаления на маке автора, пока не закончен этап 9. До этого всё
  проверяется на фейковой ФС и в режиме `--dry-run`.
- Сборка в `~/Developer/doclean`, не на Рабочем столе (iCloud-атрибуты ломают подпись).
- Если этап застрял больше чем на час, он упрощается, а проблема записывается в лог.
  Ночь не встаёт целиком из-за одной фичи.

## Этап 0. Каркас (≈20 мин)
- SwiftPM-пакет: `DoCleanCore`, `DoCleanUI`, исполняемые `DoClean` (app) и `doclean` (CLI), тесты.
- `Tools/build.sh`, `Tools/bundle.sh` (→ `build/do clean.app`, ad-hoc подпись), `Tools/test.sh`.
- `.gitignore`, README-заготовка, CHANGELOG.
- **Готово, когда:** пустое окно запускается из `.app`, `swift test` проходит.

## Этап 1. Ядро сканирования (≈60 мин)
- Модель `Rule` (id, название RU/EN, уровень, корни, глоб-маски, фильтр по возрасту, `requiresAppClosed`,
  способ удаления, «почему безопасно»), загрузка каталога из `Rules/*.json`.
- `Scanner`: параллельный обход, реальный занятый размер (`totalFileAllocatedSize`), отмена, прогресс.
- `SafetyGuard`: запрещённые корни, защита от симлинков, проверка «внутри корня правила».
- `AppStateProbe`: запущен ли AE/Premiere/Xcode/Blender/браузер.
- `doclean scan --json`.
- **Готово, когда:** тесты на фейковой ФС зелёные, `doclean scan` на этом маке находит AE-кэш ≈46 ГБ,
  DeviceSupport ≈24 ГБ и HuggingFace ≈10 ГБ.

## Этап 2. Каталог правил (≈45 мин)
- Все категории из SPEC §2: Система, Творческие, Разработка, AI, Личное.
- Особые правила: DeviceSupport «кроме новейшей версии», симуляторы через `simctl`,
  `brew cleanup`, Docker через `docker system df`, `node_modules` по давности проекта,
  HuggingFace по моделям.
- **Готово, когда:** у каждого правила есть тест; ни одно правило не попадает в запрещённые пути
  (отдельный тест прогоняет все корни через SafetyGuard).

## Этап 3. Очистка и история (≈40 мин)
- `Cleaner`: удаление (зелёный) / Корзина (жёлтый, красный), повторная проверка перед удалением
  (файл не изменился после скана), частичные ошибки не роняют всю очистку.
- `History`: записи «дата, правило, байты», итог «освобождено всего».
- `doclean clean --dry-run` и `--rules …`.
- **Готово, когда:** тесты удаления на фейковой ФС проходят, dry-run на реальном маке печатает план.

## Этап 4. Дизайн-система (≈60 мин)
- `DotMatrixNumber` (Canvas, 5×7, анимированный пересчёт), `GlassCard`, `MeshBlur`
  (цветное размытие, мягкое «дыхание»), `TickScale` с маркером, `DiskRing`, кнопки.
- Палитры категорий, типографика, Reduce Motion.
- Галерея компонентов (`-gallery`) для проверки скриншотами.
- **Готово, когда:** скриншот галереи визуально совпадает по духу с референсом.

## Этап 5. Главная + сканирование + результаты (≈90 мин)
- Dashboard: сетка карточек, свободное место, режимы Быстро / Глубоко / Всё, кнопка «Сканировать».
- Экран сканирования с живыми карточками.
- Результаты: группы по уровням, галочки, «почему безопасно», раскрытие до файлов,
  Reveal in Finder, QuickLook, подсказка «закрой программу X, чтобы освободить N ГБ».
- **Готово, когда:** полный путь «скан → выбор → dry-run-очистка» проходит в приложении.

## Этап 6. Очистка в UI + экран «Освобождено» (≈30 мин)
- Подтверждение (для красного уровня: явный список файлов), прогресс, итоговый экран «было → стало».

## Этап 7. Инструменты (≈75 мин)
- Большие файлы (порог настраивается), Дубликаты (размер → частичный хеш → SHA-256),
  Загрузки (фильтры: старше 30/90 дней, установщики, всё), `node_modules`.
- **Готово, когда:** у каждого инструмента есть тест на фейковой ФС и рабочий экран.

## Этап 8. Обвязка (≈60 мин)
- Онбординг с Full Disk Access (приложение само замечает выдачу).
- Настройки: исключения, напоминание (UserNotifications), порог больших файлов, язык RU/EN,
  автозапуск.
- Меню-бар виджет со свободным местом и «Быстрой чисткой».
- История с графиком.
- Иконка приложения (генерируется скриптом в стиле карточек: стеклянный сквирекл с градиентом
  и точечным «do»).

## Этап 9. Боевой QA (≈45 мин)
- `-selftest`: 0 падений.
- Скриншоты всех экранов, проверка на маленьком окне.
- Реальная проверка на маке автора **только зелёного уровня** и только кэшей, которые точно
  восстанавливаются (например DerivedData, Homebrew). Остальное утром руками, вместе.
- Проверка производительности: полный скан домашней папки меньше чем за 60 с.

## Этап 10. GitHub и релиз (≈30 мин)
- README RU/EN со скриншотами и инструкцией «первый запуск без Developer ID», CHANGELOG, лицензия.

- `gh repo create do-clean --private`, push, `gh release create v1.0.0` с dmg.
- **Делается только после «да» автора** (создание репо и пуш = публикация наружу).

## Этап 11. Structurize (добавлено 2026-10-19, «для счастья»)
Помогает разложить файлы по удобной структуре папок. **Ничего не удаляет, только перемещает, и всё можно отменить.**

- **Источники:** Рабочий стол, Загрузки, Документы, любая папка по выбору.
- **Готовые структуры (предложения):**
  - «По типу»: Видео / Фото / Документы / Архивы / Установщики / Аудио / Дизайн / Код
  - «По дате»: `2026/10 Октябрь`
  - «Творческий»: `Проекты/<проект>/{Исходники, Рендеры, Монтаж, Звук, Экспорт}`, проект угадывается по общему префиксу имён и папкам
  - «Минимал»: Входящие / В работе / Архив
- **Всё настраивается:** переименовать папки, правила «расширение или маска → папка», включить или выключить правило, сохранить свою структуру как пресет.
- **Превью «было → станет»** деревом, со счётчиками. Применяется только по кнопке.
- **Безопасность:**
  - Папка с `.prproj`, `.aep`, `.blend`, `.xcodeproj`, `.fcpbundle`, `.git` переезжает целиком, внутрь неё не лезем: иначе сломаются ссылки на медиа.
  - Не трогаем `.app`, бандлы, файлы, открытые прямо сейчас, и iCloud-заглушки.
  - Конфликты имён решаются суффиксом « 2».
  - Журнал перемещений даёт «Отменить раскладку» (undo всей операции).
  - Ночью только dry-run.
- **Экран:** карточки-пресеты в нашем стиле → настройка → превью → «Разложить» → экран «Готово» с кнопкой «Отменить».
